# Проект 3: Непрерывность между сессиями

Добавьте агенту контроль скоупа и проверочные шлюзы, чтобы он продолжал работу через перезапуски сессий. Реализуйте чанкование документов, извлечение метаданных, отображение прогресса индексации и Q&A-флоу с цитатами. Используйте `feature_list.json` для отслеживания статуса фич — по одной фиче за раз, и никакого «pass» без доказательств верификации.

## Цель

Спроектировать файлы состояния и инициализационные скрипты, чтобы агент мог бесшовно продолжать работу между сессиями. Ключевые вопросы: теряет ли агент состояние между несколькими функциями? Есть ли доказательство проверки перед отметкой функции как готовой?

## Шаги

1. Возьмите код Project 02 (indexing и Q&A с цитатами ещё не завершены) из каталога `projects/project-03/starter/`.
2. **Первый запуск:** без ограничений и без финальных файлов handoff/restart. Зафиксируйте, теряет ли агент состояние и уходит ли в сторону между функциями.
3. **Второй запуск:** со строгим контролем — `init.sh`, `session-handoff.md`, `claude-progress.md`, `clean-state-checklist.md`.
4. Сравните оба запуска по непрерывности и доказательности завершения.

## Код

Набор файлов непрерывности (каталог `solution/`):

```
solution/
├── init.sh                  # инициализация перед каждой сессией
├── feature_list.json        # статус фич (по одной активной за раз)
├── session-handoff.md       # передача между сессиями
├── claude-progress.md       # журнал прогресса
└── clean-state-checklist.md # чек-лист чистого состояния на выходе
```

Пример правила из `init.sh` — агент всегда начинает с чтения состояния:

```bash
#!/usr/bin/env bash
set -euo pipefail

echo "== Harness init =="
cat feature_list.json | jq '.features[] | select(.state == "active")'
cat session-handoff.md
```

## Проверка

- Есть ли доказательство верификации перед тем, как функция помечена как `passing`?
- Сохранил ли агент состояние между сессиями, или начал заново?
- Сработало ли правило «одна активная фича за раз» против ухода в сторону?

Главный итог — агент, который перезапускается с чистого, но полного состояния и продолжает ровно с того места, где остановился.
