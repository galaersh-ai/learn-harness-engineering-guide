# Проект 5: Самопроверка и разделение ролей

Реализуйте разделение ролей — генератор, который пишет код, evaluator, который ревьюит, и опционально планировщик. Запустите трижды, чтобы измерить эффект каждой добавленной роли. Выберите содержательную фичу-апгрейд (многоходовой диалог, редизайн панели цитирования или фильтрация документов) и удерживайте её одинаковой во всех запусках.

## Цель

Построить независимый механизм ревью, чтобы предотвратить галлюцинации и преждевременные объявления о победе. Ключевая идея: агент, который сам себя оценивает, ненадёжен; независимый оценщик с доказательствами правок — базовая гарантия качества.

## Шаги

1. Возьмите приложение на базе Project 04 (до добавления истории диалога) из каталога `projects/project-05/starter/`.
2. **Запуск A (одна роль):** один агент планирует, реализует и сам себя оценивает. Оценка и дефекты — в `evaluator-rubric.md`.
3. **Запуск B (генератор + evaluator):** разделите роли; evaluator указывает конкретные проблемы с доказательствами.
4. **Запуск C (planner + generator + evaluator):** добавьте планировщика со sprint contract.
5. Сравните качество результата и характер найденных дефектов по всем трём запускам.

## Код

Структура ролей (каталог `solution/`):

```
solution/
├── single-role/       # один агент делает всё сам
│   └── evaluator-rubric.md
├── gen-eval/          # generator + evaluator
│   └── evaluator-rubric.md
└── plan-gen-eval/     # planner + generator + evaluator
    ├── sprint-contract.md
    └── evaluator-rubric.md
```

Пример записи оценки с доказательством:

```markdown
## Evaluation

- Feature: multi-turn dialog
- Status: fail
- Evidence: conversation history is reset on every render
  (see src/components/Chat.tsx line 42)
- Required fix: persist history in state before re-render
```

## Проверка

- Сколько дефектов нашёл каждый вариант (одна роль / gen-eval / plan-gen-eval)?
- Насколько оценка стала воспроизводимой и основанной на доказательствах?
- Снизил ли sprint contract число «предсказуемых» отказов от evaluator?

Итог — понимание, что независимый оценщик и разделение ролей повышают качество заметнее, чем «ещё один проход» того же агента.
