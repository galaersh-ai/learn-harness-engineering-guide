# Английские справочные материалы

Эти заметки объясняют, как использовать шаблоны как рабочий харнес, а не как россыпь файлов.

## Внутренние справочные заметки

- `method-map.md` — карта распространённых режимов отказа долгосрочных задач к артефакту или политике, которая решает их в первую очередь
- `initializer-agent-playbook.md` — что должен оставить инициализатор перед началом работы над функциями
- `coding-agent-startup-flow.md` — фиксированный поток запуска сессии для последующих запусков кодирования
- `prompt-calibration.md` — как поддерживать корневые инструкции актуальными, не делая их громоздкими и хрупкими

## Основные статьи

Этот список намеренно узкий. Харнес означает систему выполнения вокруг модели: цикл агента, выполнение инструментов, песочница, состояние, контекст, верификация, завершение, оркестрация и наблюдаемость. Общие статьи по prompt engineering или широкие статьи о фреймворках агентов не входят в основной список.

Три оригинальные статьи остаются основой курса:

- **OpenAI: Harness engineering: leveraging Codex in an agent-first world** (2026-02-11): репозитории в стиле agent-first, контекст на уровне репозитория, пользовательский линтинг и структурные ограничения.
- **Anthropic: Effective harnesses for long-running agents** (2025-11-26): агент-инициализатор, агент для кодирования, список функций, журнал прогресса и передача между окнами контекста.
- **Anthropic: Harness design for long-running application development** (2026-03-24): роли планировщика / генератора / оценщика, сбросы контекста, упрощение харнеса и устаревшие предположения.

Добавлены только несколько highly relevant статей 2026 года:

- **OpenAI: Unrolling the Codex agent loop** (2026-01-23): среда выполнения харнеса Codex, вызовы инструментов, рост контекста и завершение цикла.
- **Anthropic: Demystifying evals for AI agents** (2026-01-09): оценка модели и харнеса вместе, различие оценочных харнесов от агентских харнесов.
- **LangChain: Improving Deep Agents with harness engineering** (2026-02-17): удержание модели фиксированной при улучшении системных промптов, инструментов, промежуточного ПО, трассировки и самопроверки для перехода агента кодирования с Top 30 на Top 5 в Terminal Bench 2.0.
- **Thoughtworks / Martin Fowler: Harness engineering for coding agent users** (2026-04-02): харнесы пользователей агентов кодирования как прямые руководства и обратные датчики с детерминистическими и инференциальными контроллерами.
- **Cursor: Continually improving our agent harness** (2026-04-30): рассмотрение харнеса как непрерывно улучшаемой продуктовой системы с офлайн-оценками, онлайн-метриками, таксономией ошибок инструментов, настройкой под конкретную модель и переключением модели в середине чата.

## Расширенные ссылки 2026 года

Это не основные источники курса, но они полезны при проектировании конкретных модулей харнеса. Этот раздел сохраняет только источники, тело которых непосредственно охватывает цикл агента, выполнение инструментов, управление контекстом, верификацию, песочницу, уровни контроля или управление регрессиями. Чистые агентские продукты, объявления платформ, тематические исследования команд и бенчмарки исключены.

- **OpenAI: Unlocking the Codex harness: how we built the App Server** (2026-02-04): харнес как многоразовый протокол App Server с жизненным циклом потока, возобновлением, форком, диффами и клиентскими интеграциями.
- **OpenAI Developers: Run long horizon tasks with Codex** (2026-02-23): долговечная память проекта, валидация вех и примеры «done-when» для долгосрочных задач.
- **OpenAI: The next evolution of the Agents SDK** (2026-04-15): харнесы, нативные для модели, выполнение в песочнице и выполнение файлов/команд.
- **OpenAI: An open-source spec for Codex orchestration: Symphony** (2026-04-27): превращение трекера задач или доски Linear в мультиагентную панель управления.
- **Anthropic: Building a C compiler with a team of parallel Claudes** (2026-02-05): параллельные команды агентов, блокировки задач, синхронизация git, изоляция контейнеров и автономные циклы.
- **Anthropic: Scaling Managed Agents: Decoupling the brain from the hands** (2026-04-08): мета-харнес, разделяющий сессию, харнес и песочницу как заменяемые интерфейсы.
- **Anthropic: An update on recent Claude Code quality reports** (2026-04-23): усилие рассуждения, обрезка контекста и системные промпты как изменения харнеса, требующие управления регрессиями.
- **LangChain: Context Management for Deep Agents** (2026-01-28): выгрузка на файловую систему, усечение вызовов инструментов, суммаризация и целевые оценки для харнесов управления контекстом.
- **LangChain: Tuning Deep Agents to Work Well with Different Models** (2026-04-29): профили харнеса, специфичные для модели, для промптов, имён инструментов, промежуточного ПО и конфигурации субагентов.
- **LangChain: Continual learning for AI agents** (2026-04-05): разделение улучшения агента на модель, харнес и уровни контекста на основе трассировок.
- **Microsoft: Agent Harness in Agent Framework** (2026-03-12): харнесы shell/файловой системы, поток одобрения, выполненение hosted shell и сжатие контекста.
- **Google: Announcing ADK for Java 1.0.0** (2026-03-30): плагины, сжатие событий, HITL, сервисы сессий/памяти и A2A как многоразовые примитивы харнеса.
- **GitHub: Automate repository tasks with GitHub Agentic Workflows** (2026-02-13): GitHub Actions как раннер агентских рабочих процессов с безопасными выходами, песочницей, разрешениями и ревью.
- **AWS: AI agents in enterprises: Best practices with Amazon Bedrock AgentCore** (2026-02-03): корпоративные уровни харнеса через Runtime, Memory, Gateway, Identity/Policy, Observability и Evaluations.
- **Stripe: Minions: Stripe's one-shot, end-to-end coding agents** (2026-02-09) и **Part 2** (2026-02-19): изоляция devbox, пользовательские харнесы агентов, конечные автоматы blueprint, файлы правил, курирование инструментов MCP, контроли безопасности и циклы обратной связи pre-push/CI.
- **Cognition: What We Learned Building Cloud Agents** (2026-04-23): изоляция VM, снимок/возобновление сессии, оркестрация, управление, аудит-логирование и интеграции для сред выполнения облачных агентов.
- **Cognition: Multi-Agents: What's Actually Working** (2026-04-22): циклы генератор-верификатор, ревьюеры чистого контекста, маршрутизация smart-friend, координация manager-child и границы межагентной коммуникации.
- **Addy Osmani: Loop Engineering** (2026-06-07): полный фреймворк инженерии циклов от `/goal` до шести примитивов — автоматизации, worktrees, навыки, коннекторы, субагенты, внешнее состояние — плюс четыре скрытых издержки.

- **Vercel: How we made v0 an effective coding agent** (2026-01-07): динамические системные промпты, слой потоковой перезаписи и детерминистические/модель-управляемые автофиксеры.
- **Vercel: Introducing deepsec** (2026-05-04): харнес агента кодирования, ориентированный на безопасность, с шагами сканирования, исследования, ревалидации, обогащения, экспорта, плагина и проверки отказа.
- **Sourcegraph: CodeScaleBench** (2026-03-03): справочный харнес оценки/инструментов, охватывающий принятие инструментов MCP, транскрипты использования инструментов, QA бенчмарков, врата верификатора/воспроизводимости и итерацию промптов/преамбул.
