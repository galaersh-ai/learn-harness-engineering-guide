# Английская библиотека ресурсов

Эта папка превращает методы курса в готовые к использованию шаблоны и компактные справочники, которые можно использовать в реальном репозитории.

## Когда использовать

Начните здесь, когда хотите, чтобы Codex, Claude Code или другой агент для написания кода работал в нескольких сессиях, не переопределяя каждый раз настройки, статус и область видимости.

Это особенно полезно, когда:

- работа охватывает несколько сессий
- функции многочисленны и легко остаются незавершёнными
- агенты склонны объявлять о завершении слишком рано
- шаги запуска переопределяются каждый раз

## Начало работы

Для минимальной настройки начните с:

- корневые инструкции: `templates/AGENTS.md` или `templates/CLAUDE.md`
- состояние функций: `templates/feature_list.json`
- журнал прогресса: `templates/claude-progress.md`
- справочник скрипта инициализации: `docs/en/resources/templates/init.sh`

Затем добавьте:

- передача сессии: `templates/session-handoff.md`
- чеклист чистого выхода: `templates/clean-state-checklist.md`
- рубрика оценщика: `templates/evaluator-rubric.md`

Если вы хотите более полную структуру репозитория в стиле OpenAI из статьи «Harness engineering», используйте продвинутый пакет:

- `openai-advanced/index.md`

## Структура библиотеки

- `templates/` — шаблоны для копирования в реальный репозиторий
- `reference/` — методологические заметки, поток запуска и карты режимов отказа
- `openai-advanced/` — продвинутый скелет репозитория, документы системы записи и шаблоны управления в стиле agent-first

## Рекомендуемый минимальный пакет

- `AGENTS.md` или `CLAUDE.md`
- `feature_list.json`
- `claude-progress.md` (общий журнал прогресса сессии; историческое имя файла)
- `init.sh`

Этих четырёх файлов достаточно, чтобы сделать большинство рабочих процессов агентов заметно более стабильными.

Когда репозиторий вырастет в более долгосрочную систему с несколькими доменами, активными планами, оценкой качества и политиками надёжности, переходите к пакету `openai-advanced/` вместо того, чтобы растягивать минимальный пакет.
