# Навыки

Этот каталог содержит встроенные навыки AI-агентов, которые поставляются с курсом. Навыки — это автономные шаблонов промптов, которые могут быть загружены AI-агентами для кодирования (Claude Code, Codex, Cursor, Windsurf и др.) для выполнения специализированных задач.

## harness-creator

Навык промышленного уровня для инженерии харнесов AI-агентов. Помогает создавать, оценивать и улучшать пять основных подсистем харнеса: инструкции, состояние, верификация, область видимости и жизненный цикл сессии.

### Что он делает

- **Создаёт харнесы с нуля** — AGENTS.md, списки функций, рабочие процессы верификации
- **Улучшает существующие харнесы** — оценка пяти подсистем с приоритизированными улучшениями
- **Проектирует преемственность сессий** — сохранение памяти, отслеживание прогресса, процедуры передачи
- **Применяет промышленные паттерны** — память, инженерия контекста, безопасность инструментов, координация мультиагентов

### Быстрый старт

Файлы навыков находятся в репозитории по пути `skills/harness-creator/`.

```bash
npx skills add walkinglabs/learn-harness-engineering --skill harness-creator
```

Для использования с Claude Code скопируйте каталог `harness-creator/` в путь навыков вашего проекта или укажите агенту на файл SKILL.md.

### Справочные паттерны

Навык включает 7 сфокусированных справочных документов:

| Паттерн | Когда использовать |
|---|---|
| Memory Persistence | Агент забывает между сессиями |
| Skill Runtime | Упаковка многоразовых рабочих процессов как навыков |
| Context Engineering | Управление бюджетом контекста, JIT-загрузка |
| Tool Registry | Безопасность инструментов, контроль конкурентности |
| Multi-Agent Coordination | Параллелизм, специализированные рабочие процессы |
| Lifecycle & Bootstrap | Хуки, фоновые задачи, инициализация |
| Gotchas | 15 неочевидных режимов отказа с исправлениями |

### Шаблоны

Навык включает готовые к использованию шаблоны:

- `agents.md` — каркас AGENTS.md с рабочими правилами
- `feature-list.json` — JSON Schema + пример списка функций
- `init.sh` — стандартный скрипт инициализации
- `progress.md` — шаблон журнала прогресса сессии
- `session-handoff.md` — шаблон передачи сессии

### Скрипты

Навык также включает простые скрипты Node.js для каркасинга, валидации, HTML-отчётов об оценке и структурных отчётов бенчмарков.

### Как был создан этот навык

`harness-creator` был разработан с использованием методологии **skill-creator** — официальной мета-навык Anthropic для создания, тестирования и итерации навыков агентов. skill-creator предоставляет структурированный рабочий процесс (черновик → тест → оценка → итерация) со встроенными раннерами оценки, грейдерами и просмотрщиком бенчмарков.
